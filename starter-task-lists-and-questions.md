# Starter task lists and document checklists for review

Oct 9, 2026 · @Haydn Watkins

These are the tasks and documents a brand-new Norma user outside Pennsylvania would see on their first file. Please mark anything that is wrong, missing, unnecessary, or due at the wrong time. Every user can edit their own lists later, so this only needs to be a believable starting point for a coordinator in any state.

## Document checklists

A required document shows as missing on the file until it is marked received. An optional one is listed without that warning.

### Buyer side

| Document | Required |
| --- | --- |
| Purchase Agreement | Yes |
| Buyer Agency Agreement | Yes |
| Agency Disclosure (if your state requires one) | Optional |
| Seller Disclosure | Yes |
| Lead-Based Paint Disclosure (if built before 1978) | Optional |
| Proof of Earnest Money Deposit | Yes |
| Pre-Approval Letter (if financed) | Optional |
| Inspection Reply or Repair Addendum | Optional |
| Closing Disclosure or Settlement Statement | Yes |

### Seller side

| Document | Required |
| --- | --- |
| Purchase Agreement | Yes |
| Listing Agreement | Yes |
| Agency Disclosure (if your state requires one) | Optional |
| Seller Disclosure | Yes |
| Lead-Based Paint Disclosure (if built before 1978) | Optional |
| Proof of Earnest Money Deposit | Optional |
| Inspection Reply or Repair Addendum | Optional |
| Closing Disclosure or Settlement Statement | Yes |

Cash files also get Proof of Funds as a required document, on either side.

## Questions for you

- [ ] Are the due dates realistic? The ones most likely to be off are the inspection reply (10 days after contract), the appraisal (14 days after contract), and the loan commitment (14 days before closing).
- [ ] The financing tasks appear on every file and say "(if financed)", because the list cannot hide them on a cash file. Is that acceptable, or would you rather they were left out?
- [ ] Is anything here something you would never do, or something only one brokerage does?
- [ ] Is anything missing that you do on nearly every file?
- [ ] On the seller side, should "Update MLS Status to Pending" be on every file, or only when the agent asks?
- [ ] Are the right documents marked required? Seller Disclosure and the Closing Disclosure are required on both sides in this draft.
- [ ] "Check KW Command Compliance" and "Add to ShowingTime" are removed for new users. Your own lists do not change.

New Pennsylvania users would get the same tasks with "Agreement of Sale" and "settlement" in place of "Purchase Agreement" and "closing". Their document checklist stays as it is today, including the Consumer Notice and Estimated Closing Costs.
